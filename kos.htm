Automated Launch Script

This Script is able the launch rockets from any body into a stable and circular orbit with as little as possible deltaV.

Features:

  1. detection of launch clamps, to start the launch if on launchpad (manual start is also possible)
  2. gravity turn
  3. automatic staging
  4. fairing deploy at safe altitude
  5. automatic solar/antenna deploy
  6. "quality of life" improvements like timewarp and map view

Transfer Window

This script takes two structures as parameters and calculates the period of a hohmann transfer orbit by using keplers 3rd law and uses this time to determin the transfer phase angle. Then it timewarps until this phase angle is reached. The current angle between the structures is determined by there xyz-coordinates and the scalar product. The script always searches the common body of both structures. This means, if the start and target are two moons of different planets, the common body is the sun and the script calculates the transfer window between the planets. 		video coming soon
